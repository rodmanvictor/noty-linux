# Project identity and licenses

Noty Linux is a local-first Linux desktop project written in Qt 6, QML and C++.
KDE Plasma 6 is the first shipping desktop integration. The source, interface
and public documentation are maintained in this repository under the MIT
license.

Noty Linux is MIT-licensed under [`LICENSE`](../../LICENSE). The bundled
Phosphor Regular icons are also MIT-licensed; their license is in
[`licenses/PHOSPHOR-MIT.txt`](../../licenses/PHOSPHOR-MIT.txt). The complete
attribution wording is maintained in [`NOTICE`](../../NOTICE).
