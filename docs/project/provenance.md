# Provenance and attribution

Noty Linux is an independent Linux desktop project written in Qt 6, QML, and
C++. KDE Plasma 6 is the first shipping desktop integration. The repository
contains no Swift, SwiftUI, or AppKit source from the original project and is
not an official upstream release.

The edge-deck interaction, early UX references, and name were inspired by
[Noty for macOS](https://github.com/aimen08/noty) by Aymen Hamza. Public
material should use the wording “Independent Linux desktop implementation
inspired by Noty for macOS” with a nearby upstream link. It must not state or
imply endorsement by, affiliation with, or an official release from the
original author.

Phosphor Regular icons are also MIT-licensed; their license is in
[`licenses/PHOSPHOR-MIT.txt`](../../licenses/PHOSPHOR-MIT.txt). The complete
attribution wording is maintained in [`NOTICE`](../../NOTICE).
