# Интернационализация

Noty хранит язык интерфейса в `plasmoid.configuration.language` для каждого экземпляра виджета. Модуль `plasmoid/package/contents/ui/I18n.js` нормализует код локали, отдаёт список для ComboBox и переводит общий набор коротких подписей заметки, редактора, архива, подтверждения очистки и настроек.

Доступны десять вариантов:

- `en` — English;
- `ru` — Русский;
- `es` — Español;
- `id` — Bahasa Indonesia;
- `de` — Deutsch;
- `fr` — Français;
- `pt` — Português;
- `zh` — 中文 (упрощённый китайский);
- `ja` — 日本語;
- `hi` — हिन्दी.

Английский остаётся исходным текстом и безопасным fallback. Русский сохраняет прежние формулировки, чтобы существующее поведение не изменилось. Региональные варианты вроде `zh-CN` и `ja-JP` сводятся к базовому коду (`zh`, `ja`); неизвестное значение возвращается к `en`.

Языки называются в собственных письменных формах, поэтому список остаётся понятным при смене языка. Даты архива по-прежнему форматируются системным Qt-шаблоном: для русского используется `dd.MM.yyyy HH:mm`, для остальных языков — англоязычный компактный шаблон `MMM d, yyyy HH:mm`.

`plasmoid/tests/tst_I18n.qml` проверяет полный список кодов, нормализацию регионов и переводы ключевых поверхностей. `npm run test:plasmoid` запускает этот тест вместе с визуальными и контрактными проверками.
