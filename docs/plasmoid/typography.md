# Типографика заметок

По умолчанию карточка следует шрифту, который сейчас задан в Plasma через `Kirigami.Theme.defaultFont`. На этой системе это `Noto Sans` размером `8 pt`; при 96 DPI это около `10,7 px`. Для заметки такой текст слишком мелкий, поэтому Noty применяет тот же шрифт, но сохраняет минимум `12 px`. Так интерфейс остаётся связанным с темой, не становясь нечитабельным в компактной карточке.

В `Настроить Noty → Appearance → Typography` доступны два общих параметра экземпляра виджета:

- `Use Plasma system font`: включено по умолчанию; интерфейс показывает фактическое применяемое значение вроде `Noto Sans · 12 px`, а подсказка поясняет исходный системный point size.
- `Text size`: при отключённом системном шрифте — от 10 до 24 px.
- `Typeface`: при отключённом системном шрифте — системный `FontDialog`, который сохраняет выбранное имя гарнитуры.

Настройка действует на основной Markdown-текст и заголовок. Заголовок автоматически на 3 px крупнее основного текста, чтобы не потерять иерархию. Служебные элементы — подписи стиков, статус сохранения и маленькие кнопки — сохраняют фиксированный размер, поскольку это навигация, а не содержание заметки.

Значения живут в `plasmoid.configuration.useSystemNoteFont`, `plasmoid.configuration.noteFontSize` и `plasmoid.configuration.noteFontFamily`. `main.qml` динамически читает текущую системную гарнитуру и переводит point size в пиксели с нижней границей 12 px; ручной размер по-прежнему ограничен диапазоном 10–24 px.
