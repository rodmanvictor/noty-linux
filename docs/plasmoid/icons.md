# Единый набор иконок

Управляющие иконки Noty используют локально поставляемый поднабор [Phosphor Icons Core 2.1.1](https://phosphoricons.com/) с весом `regular`. Это один визуальный язык для карточки, архива и настроек: `plus`, `plus-circle`, `archive`, `folder-open`, `arrow-counter-clockwise`, `trash-simple`, `text-aa`, `palette`, `list` и `x`. Редактор использует штатные glyph и context-menu Qt, поэтому Phosphor-иконки в нём не рисуются. Система использует базовую сетку 24 × 24 и оптический размер 16 px для обычных действий. Hit-зоны остаются 28–32 pt, но больше не растягивают глиф. Все обычные действия имеют единый цвет `#667784`; светлая инверсия допускается только для текста на тёмном tooltip. Кнопка новой заметки — намеренно более заметное первичное действие: прозрачная область остаётся 28 × 28 pt, а отдельный глиф `plus` занимает 22 px без кружка, подложки или внешней обводки. Кнопка добавления цвета в настройках сохраняет `plus-circle`, чтобы не менять ранее выбранную палитру.

Выбранные пользователем соответствия: новая заметка — `plus`; архивирование — `archive`; открытие архива — `folder-open`; восстановление — `arrow-counter-clockwise`; удаление — `trash-simple`; шрифт — `text-aa`; палитра — `palette`; закрытие карточки и возврат к заметкам — `x`. Переключатель линеек использует близкий по смыслу `list`. Выполнение задач и форматирование текста теперь рисуются только штатным Markdown-редактором Qt.

Первичное архивирование остаётся иконкой `archive`; при наведении над ней показывается локальная короткая подсказка, а вторичное `folder-open` с подписью «Open archive / Открыть архив» появляется слева. Исходные SVG и MIT-лицензия находятся в `plasmoid/package/contents/ui/icons/`; компонент `NotyIcon.qml` задаёт единый путь загрузки.

`NotyIcon.qml` рисует исходные 256 × 256 SVG-path через нативные `QtQuick.Shapes`, а `ShapePath.fillColor` подкрашивает только сам глиф. Путь `Kirigami.Icon.isMask` для этих локальных файлов не используется: он может принять прямоугольную текстуру SVG за маску и показать сплошной цветной квадрат. Растровый `MultiEffect` также не нужен, поэтому каждая маленькая иконка не создаёт дополнительную текстуру. Файл `PhosphorPaths.js` содержит path-данные того же поставляемого поднабора, а исходные SVG и лицензия остаются каноническими ассетами. `NotyActionButton.qml` отключает зависящую от темы Plasma-подложку `ToolButton`: в покое остаётся только Phosphor-иконка, а при hover, focus и выбранном состоянии появляется лёгкая нейтральная обводка без белого круга. Это исключает смешение системных Breeze-значков, Tabler и вручную нарисованных символов. Для `archive` применяется только оптическая коррекция 1.16 внутри той же 16 × 16 hit-зоны: исходный путь ниже по высоте, поэтому без этой поправки он выглядит меньше крестика и линеек.

Каждый такой control также задаёт `Qt.PointingHandCursor`, поэтому закрытие, линейки, архивирование, восстановление, удаление и форматирование показывают палец. Самостоятельные `MouseArea` палитры, добавления и переключателя цвета используют тот же курсор. Это исключает смешение системных Breeze-значков, Tabler и вручную нарисованных символов.

В настройках есть отдельный эксперимент `Use Plasma icon theme`. При его включении `NotyIcon.qml` заменяет локальный источник на эквивалентное имя активной темы через `Kirigami.Icon`: для двух действий, которые особенно зависят от рисунка темы, выбраны `archive` → `archive` (стрелка вниз вместо малозаметного значка «добавить в архив») и `list` → `view-list-text` (ровные строки вместо маркерного списка); остальные примеры — `folder-open` → `folder-open`, `trash-simple` → `edit-delete`, `x` → `window-close`. Эти имена проверены в установленной теме `MacTahoe-dark` на размерах 16/22/24 px. Размеры остаются прежними: 16 px для обычных действий, 22 px для добавления, 28–32 pt для hit-зон. По умолчанию опция выключена и Phosphor остаётся резервным стабильным набором.

Для визуальной проверки пяти вариантов каждого из этих двух действий запускается `tst_PlasmaIconCandidates.qml`; снимок сохраняется как `build/visual-snapshots/plasma-icon-candidates.png`. В нём сравниваются `archive`, `archive-insert`, `archive-extract`, `archive-remove`, `document-preview-archive` и `view-list`, `view-list-text`, `view-list-details`, `format-list-unordered`, `view-list-tree`. Выбор закреплён в `PlasmaIconNames.js`, поэтому смена активной темы не смешивает семантику с локальным Phosphor-набором.

Спецификация размеров, сетки, доступности и проверки поддерживаемых вариантов закреплена проектным навыком `.agents/skills/icon-system/SKILL.md`, установленным из `Owl-Listener/designer-skills`. Для интерактивных состояний добавлен `.agents/skills/keyboard/SKILL.md` из `mgifford/accessibility-skills`; экспериментальный `.agents/skills/reveal-hover-effect/SKILL.md` оставлен для будущих hover-прототипов. Версии источников фиксируются в `skills-lock.json`.
