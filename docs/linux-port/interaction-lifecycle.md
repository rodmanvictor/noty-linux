# Жизненный цикл колоды

Вкладки автоматически возвращаются в состояние **Pill** через четыре секунды бездействия. Если окно Noty теряет фокус, открытая или раскрытая колода также сворачивается в Pill через 150 мс. Задержка нужна, потому что при клике по вкладке XWayland может кратко передать фокус между окнами до завершения того же клика.

Закреплённая заметка — исключение: она не закрывается от потери фокуса. Её по-прежнему можно закрыть явно кнопкой или клавишей Esc.

Диалоги быстрой записи, библиотеки и архива не запускают сворачивание, пока они видимы.
