# Noty Linux для KDE Plasma 6

Noty Linux — локальный виджет заметок для KDE Plasma 6. Он оставляет небольшие
вкладки у края экрана и открывает заметку только тогда, когда она нужна.

## Установка

Склонируйте репозиторий и обновите локальный пакет Plasma:

```bash
git clone https://github.com/rodmanvictor/noty-linux.git
cd noty-linux
kpackagetool6 --type Plasma/Applet --upgrade plasmoid/package
```

Откройте режим редактирования рабочего стола Plasma, выберите **Добавить
виджеты**, найдите **Noty** и разместите его у края экрана.

## Что есть в виджете

- Локальные заметки, вкладки у края экрана, редактируемая карточка и Markdown
  с интерактивными пунктами чек-листа.
- Изменяемая и переставляемая пастельная палитра, лёгкие линейки и стили Noty,
  Adaptive и Plasma.
- Архив с восстановлением, полной очисткой и настраиваемым сроком хранения.
- Встроенный набор Phosphor Regular и дополнительный режим системной темы
  иконок Plasma.
- Интерфейс на английском, русском, испанском, индонезийском, немецком,
  французском, португальском, китайском, японском и хинди.

## Текущие ограничения

Сейчас поддерживается KDE Plasma 6. Версия для GNOME планируется, но пока не
выпущена. Заметки хранятся в локальной конфигурации виджета Plasma: между
устройствами они не синхронизируются, облачного сервиса нет.

## Проверка исходников

```bash
npm run docs:check
npm run test:site
npm run test:plasmoid
```

Для `test:plasmoid` нужен QML test runner из Qt 6; в среде разработки KDE/Qt
команда также создаёт визуальные снимки.
