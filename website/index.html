One note, two distances.

Tabs keep several notes reachable without a pile of windows. Opening one gives it the space to write, format, recolour, archive, or simply close it again.

Keep it local
Notes and archive recovery stay on the machine. Retention is configurable, and removing a palette colour safely falls back to the first colour.
Make it yours
Choose colours, reorder the palette, use optional ruled paper, adjust typography, and switch among Noty, Adaptive, and Plasma appearance modes.
Stay out of the way
Spread the tabs across the available edge, then open only the note you need. The interface is translated into ten languages, including English, Spanish, German, French, Portuguese, Chinese, Japanese, Hindi, Indonesian, and Russian.

Start with Plasma.

Noty Linux is free and open source. Clone the repository, install the Plasma package, then add Noty from Plasma’s widget picker.

$ git clone https://github.com/rodmanvictor/noty-linux.git
$ cd noty-linux
$ kpackagetool6 --type Plasma/Applet --upgrade plasmoid/package

Requires KDE Plasma 6 and the standard Plasma package tool.

Independent by design.

Noty Linux is a new Qt/QML and C++ implementation for Linux desktops. The interaction idea, early visual references, and name were inspired by Noty for macOS by Aymen Hamza. No Swift, SwiftUI, or AppKit source has been copied, and this project is not an official upstream fork or endorsement.

The bundled interface icons use Phosphor Icons in the Regular weight. Both the project and its icon attribution are documented in the repository.
